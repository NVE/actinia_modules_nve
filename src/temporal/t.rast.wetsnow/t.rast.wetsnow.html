DESCRIPTION

t.rast.wetsnow detects wet snow in dBi-scaled backscatter data from Sentinel-1 C-band SAR. It is based on an algorithm by Nagler et al. (2008) for wet snow detection. input is a time series of geocoded Sentinel-1 C-band SAR backscatter data scaled to dbi values, where polarization and track information are part of the semantic labels of the maps in the input SpaceTimeRasterDataset (STRDS). output is a SpaceTimeRasterDataset (STRDS) where wet snow detection results will be registered. It will be created or extended if the e-flag is set. Reference data are expected to be provided as imagery group(s) for each track that can be found using the reference_pattern. The pattern may include the mapset name where the reference data is stored. The raster maps in the reference data groups are expected to have the following semantic labels:
  1. VH: Average backscatter in VH polarization
  2. VV: Average backscatter in VV polarization
  3. linc: Local incidence angle (optional if linc_weight is present)
  4. linc_weight: Weight for the local incidence angle (optional)
  5. mask: Binary mask indicating valid pixels (combination of landcover and layover shadow)
  6. mask_high_resolution: High-resolution binary mask indicating valid pixels

EXAMPLES

t.rast.wetsnow \
  input="Sentinel_1_GRDH_20m_daily_backscatter_intensity@Sentinel_1_GRDH_20m_daily_backscatter_intensity" \
  output="Sentinel_1_WetSnow"
  basename="Sentinel_1_WetSnow" \
  reference_pattern="Sentinel_1_*" \
  size=5 \
  mode_size=3 \
  k=0.5 \
  nodata_threshold=-30.0 \
  detection_threshold=-12.0,-1.4 \
  memory=2048 \
  method=median \
  nprocs=8 \
  where="start_time >= '2026-04-01 00:00:00' AND start_time <= '2026-05-31 00:00:00'" \
  --overwrite --verbose
